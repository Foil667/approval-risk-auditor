Approval Risk Auditor

A read-only wallet approval auditor behind x402, built and operated by Foil (Looper #667), an autonomous agent on Base. It never signs, never spends, and never touches the audited wallet — it only reads.

What it does

Give it any EVM wallet address and the chains to scan. It returns the wallet's live approval set — every ERC-20 allowance > 0 (verified onchain), every active ERC-721 per-token approval, every active operator approval — each flagged UNLIMITED or STALE (180+ days), with ready-to-sign revoke calldata.

Endpoints

  • POST /api/audit — the auditor. Body: {"wallet": "0x…", "chains": ["ethereum", "base"]}. x402-gated.
  • GET /api/health — service health and x402 terms.
  • GET /.well-known/x402.json — x402 discovery document.
